Задание 1: Анимация появления элемента

Создайте функцию, которая будет добавлять элемент на страницу с анимацией появления. Элемент должен плавно увеличивать свою непрозрачность от 0 до 1.
Подсказки:

Используйте CSS-свойство opacity и transition.

Добавьте класс к элементу после его создания, чтобы запустить анимацию.

Задание 2: Анимация перемещения

Создайте функцию, которая будет перемещать элемент с одного места на другое с помощью анимации. Элемент должен плавно перемещаться по экрану.
Подсказки:

Используйте CSS-свойство transform и transition.

Измените translateX и translateY для перемещения элемента.
Задание 3: Анимация вращения

Создайте элемент, который будет вращаться вокруг своей оси. При нажатии на элемент он должен начать вращаться и остановиться через 3 секунды.
Подсказки:

Используйте CSS-свойство transform: rotate().

Используйте setTimeout для остановки анимации.
Задание 4: Анимация изменения цвета

Создайте элемент, который будет менять цвет фона при наведении курсора. Цвет должен плавно переходить от одного к другому.
Подсказки:

Используйте CSS-свойство background-color и transition.

Добавьте обработчик события mouseover и mouseout.
Задание 5: Анимация последовательного появления

Создайте несколько элементов, которые будут появляться один за другим с задержкой. Например, три квадрата, которые появляются с интервалом в 0.5 секунды.
Подсказки:

Используйте setTimeout для создания задержки между появлением элементов.

Примените анимацию появления, как в задании 1.
Задание 6: Анимация "прыжка"

Создайте элемент, который будет "прыгать" при нажатии на него. Элемент должен подниматься вверх и возвращаться обратно.
Подсказки:

Используйте CSS-свойство transform: translateY().

Используйте transition для плавного эффекта.
Задание 7: Анимация с использованием ключевых кадров

Создайте анимацию с использованием @keyframes, чтобы элемент перемещался по кругу.
Подсказки:

Определите ключевые кадры для анимации.

Примените анимацию к элементу с помощью CSS.
Задание 8: Анимация с изменением размера

Создайте элемент, который будет увеличиваться в размере при наведении курсора и возвращаться к исходному размеру при уходе курсора.
Подсказки:

Используйте CSS-свойства transform: scale() и transition.
